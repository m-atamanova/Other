ФАЙЛ callcenter_prediction_LESSON_1

Нужно было предстаказать звонок в колл-центр без использования ML инструментов
Что делала: выдвигала гипотезы, проверяла их, присоединяла датафреймы друг к другу, создавала новые, смотрела данные по разным маскам, строила графики,
накладывала их друг на друга, раскрашивала и т.д.
В итоге: нашла вероятность получить звонок, применила её к тестовым данным.
